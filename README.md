# Linux Systems Administration

## Overview
This repository documents my hands-on development in Linux systems administration, server operations, security, troubleshooting, and automation.

The purpose of this portfolio is to demonstrate practical infrastructure management skills through reproducible exercises, technical documentation, and validated troubleshooting scenarios.

## Technical Focus
- Linux installation and server deployment
- Linux command-line operations
- User and group management
- File systems and permissions
- Processes and system services
- Storage management and disk troubleshooting
- Networking and connectivity diagnostics
- System logs and performance monitoring
- SSH and remote administration
- Bash scripting and task automation
- System hardening and security fundamentals
- Backup, recovery, and scheduled maintenance
